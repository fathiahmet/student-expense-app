# App Name: EduPay

## App Overview

EduPay is a Flutter-based student expense control mobile application that allows students to track their income, manage daily expenses, set monthly budgets, and view financial summaries.

## Goals

- Help students monitor and manage their finances
- Provide a clear record of all income and expenses
- Enable budget planning and tracking
- Offer a user-friendly interface suitable for beginners

## Features

- Expense Tracking: Log daily spending with categories
- Income Management: Track all income sources
- Budget Planning: Set and monitor monthly budgets
- Expense History: View, edit, and delete transactions
- Dark Mode: Easy on the eyes for late-night use

## Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev) installed on your machine
- An editor like [Visual Studio Code](https://visualstudio.com) or Android Studio

### Installation

1. Clone the repository:

   git clone https://github.com/your-username/edupay.git

2. Navigate to the project folder:

   cd edupay

3. Install dependencies:

   flutter pub get

4. Run the app:

   flutter run
